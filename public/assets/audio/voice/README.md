# 战场人声 / 军号

来源：**火山方舟 Seedance 2.5**（`doubao-seedance-2-5-260628`，文生视频，开启原生音频 `generate_audio`）。
生成后用 ffmpeg 抽出音轨、切掉首尾杂音、响度归一到 **-16 LUFS**，再转成 44.1 kHz 单声道 ogg / mp3 / m4a。
冲锋号改用 Bilibili 视频 `BV1KS4y1k7HW`（UP：深夜星空W，13.9 秒）下载后提取的音轨，替换了原来的 Seedance 版本。
骂阵一条的 Seedance 生成结果把“鬼子”念成了“拐子”，因此保留画面、台词改用 Edge TTS（`zh-CN-YunjianNeural`）重录，并叠加爆炸与远处枪声底噪。
`radio-objective` 是电台命令，Seedance 原声的语音被埋在爆炸低频里，因此再走一遍 `tools/radioize.py`：4 阶 320–3000 Hz 窄带、
静态增益、电子管饱和、10 bit 量化，再叠载波底噪与随机噼啪，最后 loudnorm 到 -16 LUFS——这条是唯一不靠后期“贴”空间感、
而是直接把音色做成野战电台的人声。

## 配套视频

`public/assets/video/sfx/` 下是 Seedance 2.5 生成的 480p 画面（H.264 + AAC）：

- `<name>.mp4`：成片，Seedance 画面 + 归一后的音效，可直接剪进宣传片。
- `<name>-audio.mp4`：只有音轨的 mp4（AAC），用于“音效转 mp4”的交付形式。
- `battle-voices-compilation.mp4`：四条音效按顺序拼成的合集，方便试听。
- `radio-objective.mp4`：电台命令的成片（854×480，8 秒）。画面是 Seedance 2.5 生成的，声音换成上面那条
  `radio-objective` 并补了 3.7 秒载波尾噪；左上角的“AI 生成”水印用 ffmpeg `delogo` 去掉。

## 复核

用 ASR（`doubao-seed-2-1-lite`）逐条回听转写：crowd 为“冲呀！杀呀！”，curse 为“美国鬼子，我操你妈！”，
order 为“开始，干死美国佬！”；bugle 无对白，源片为纯军号、几乎无底噪，两段吹奏中间约 0.5 秒停顿。

> 注：`public/assets/video/` 下四张战役循环视频本身没有音轨，无法从中提取声音。
> 冲锋号源片是扩音喇叭转录，带有轻微电子失真与空间扩散感；这是原视频本身的质感，未做降噪处理。

## 游戏内触发

在 `src/core/Audio.js` 里注册为 `voice` 组，`Game.updateBattleVoices()` 按 `Game.js` 的 `INTRO_BEATS` 表播放，
单位是开局后的秒数：

- **约 0.25 秒**：电台命令《歼灭全部美军，占领目标点》（`radio-objective`，4.3 秒）。这条走 `Audio.radio()`，是玩家耳机里的第一人称电台：
  不进 `sfx` 世界总线，因此没有距离衰减、没有声像、没有混响；单独走耳机总线，增益 2.3 倍，播放期间把世界总线压到 0.5（−6 dB），说完 4.3 秒后 0.6 秒内恢复——所以它比枪声和喊话都靠前。
- **约 4.65 秒**：指挥员接令后吼《开始！干死美国佬！》，正好卡在电台尾噪消失的位置
- **约 5.85 秒**：八路军冲锋号（13.7 秒，覆盖整个冲锋起步）
- **约 8.75 秒**：集体喊杀《冲呀！杀呀！》
- **约 18.25 秒**：士兵怒骂《美国鬼子，我操你妈！》，作为冲锋遇阻的情绪点
- **之后每次按 Shift + W 发起新的向前冲刺**：有 12–19 秒冷却，随机触发喊杀或骂阵，不会连成循环

时间点是每次任务开局固定重排的（`startMission()` 会重置 `_voiceIntro`），但**声音本身不固定**：
四句喊话走 `Audio.shout()`，每次播放重新抽一次站位与音量；电台那条走 `Audio.radio()`，在耳机总线上固定居中、固定响度——

- 距离 `near`–`far` 米，向近处偏置采样（口令 3–8 m、骂阵 2–9 m、喊杀 3–18 m、军号 9–22 m），由 `rollout()` 做距离衰减；
- 方位在 ±`arc` 弧度内随机（骂阵约 ±57°，口令约 ±20°），映射成立体声 pan；身后的声音额外做一点高频遮蔽（`muffle`），因为人耳靠耳廓阴影分辨前后；
- 音量再叠 0.7–1.25 倍的“嗓门抖动”（约 ±3 dB），加上 ±6% 音高和 0–30 ms 的起唱抖动，远距离另加 `dist / 343` 的声速延迟；
- 喊杀用 `crowd: 2` 额外叠 1–2 个人，各自站位、音量不同，起唱错开 20–150 ms，听感是一群人在身边，而不是一支喇叭。

因此同一段采样每次响起来的位置、朝向和响度都不一样。
